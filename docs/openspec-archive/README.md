# OpenSpec Archive (retired)

This directory is a read-only historical archive of the repository's former
OpenSpec workflow. OpenSpec was removed as a dependency in favor of a
dedicated task-management system with integrated SDD, so these artifacts are
no longer live inputs to validation or publishing.

Contents, moved verbatim from the former root `openspec/`:

- `changes/` — archived change proposals, designs, delta specs, and task lists.
- `specs/` — the last canonical capability specs before retirement.
- `config.yaml` — the former OpenSpec `spec-driven` profile (kept for context only).

Do not add new changes or specs here. The replacement workflow owns current
planning artifacts elsewhere.
